# Fonte da marca: TT Hoves Pro

O manual de marca FERSA usa a **TT Hoves Pro** (fundição TypeType), que é comercial. Para usá-la no portal, coloque aqui os arquivos `.woff2` da licença web da FERSA com estes nomes:

```
TTHovesPro-Light.woff2
TTHovesPro-Regular.woff2
TTHovesPro-Medium.woff2
TTHovesPro-Bold.woff2
```

Outros pesos (`Thin`, `Black`) e itálicos (`TTHovesPro-RegularItalic.woff2`) também são reconhecidos. O build detecta os arquivos sozinho (`src/lib/fonteDaMarca.ts`); não é preciso mudar código nem CSS.

Sem os arquivos, o portal usa a **Albert Sans**, a fonte livre mais parecida (mesmas proporções geométricas, "a" de dois andares e "g" de um andar).
